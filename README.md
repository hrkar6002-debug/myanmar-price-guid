# myanmar-price-guid
Myanmar city-by-city rice, oil and commodity price guide
# 🇲🇲 မြန်မာနိုင်ငံ ကုန်ဈေးနှုန်းနှင့် ဒေသထွက်ကုန်လမ်းညွှန် (Myanmar Price & Commodity Guide)

မြန်မာနိုင်ငံတစ်ဝန်းရှိ တိုင်းဒေသကြီးနှင့် ပြည်နယ်အသီးီးရှိ မြို့နယ်များအလိုက် ဆန်၊ ဆီ၊ သီးနှံစပါး၊ လယ်ယာထွက်ကုန်များနှင့် အခြေခံစားသောက်ကုန်များ၏ နေ့စဉ်ဈေးနှုန်းများကို တစ်နေရာတည်းတွင် အလွယ်တကူ ရှာဖွေကြည့်ရှုနိုင်သော ဝဘ်အက်ပလီကေးရှင်း ဖြစ်ပါသည်။

### 🌟 အဓိက လုပ်ဆောင်ချက်များ (Key Features)
* **ဒေသအစုံ ပါဝင်ခြင်း:** တိုင်းဒေသကြီးနှင့် ပြည်နယ် (၁၅) ခုပါ မြို့နယ်စုံမှ ဈေးနှုန်းအချက်အလက်များ။
* **အမျိုးအစားအလိုက် စစ်ထုတ်ခြင်း (Category Filter):** လယ်ယာထွက်ကုန်၊ သီးနှံစပါး၊ ဆီနှင့်ဆီထွက်သီးနှံ၊ သစ်သီးဝလံနှင့် ရေထွက်ကုန်များ ခွဲခြားကြည့်ရှုနိုင်ခြင်း။
* **အမြန်ရှာဖွေမှု (Fast Search):** လိုချင်သော ကုန်ပစ္စည်းအမည်ကို ရိုက်ထည့်ရုံဖြင့် ချက်ချင်းရှာဖွေနိုင်ခြင်း။
* **နေ့စဉ် အပ်ဒိတ်များ (Daily Price Updates):** ဈေးကွက်အတွင်း ဖြစ်ပေါ်နေသော နေ့စဉ်ဈေးနှုန်း အပြောင်းအလဲများကို အချိန်နှင့်တပြေးညီ ဖော်ပြပေးခြင်း။

### 💻 အသုံးပြုပုံ
1. အထက်ပါ **Category Filter** မှ လိုချင်သော ကုန်စည်အမျိုးအစားကို ရွေးချယ်ပါ။
2. **Region Filter** တွင် မိမိသိလိုသော တိုင်းဒေသကြီး သို့မဟုတ် မြို့နယ်ကို ရွေးချယ်ပါ။
3. ရှာဖွေလိုသည့် ပစ္စည်းအမည်ကို **Search Bar** တွင် ရိုက်ထည့်၍ ချက်ချင်း ကြည့်ရှုနိုင်ပါသည်။
